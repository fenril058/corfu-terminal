# corfu-terminal — codeberg mirror

Read-only mirror of <https://codeberg.org/akib/emacs-corfu-terminal>.

- **`master`** tracks upstream verbatim, force-synced by
  [`.github/workflows/sync-upstream.yml`](.github/workflows/sync-upstream.yml).
- **`mirror`** (default branch) holds only the sync workflow and this README;
  do not put package code here.

This mirror exists so that
[fenril058/emacs-config](https://github.com/fenril058/emacs-config) can build
the package without depending on codeberg.org being reachable in CI.

Upstream is licensed GPL-3.0-or-later by Akib Azmain Turja. All rights and
attribution remain with upstream; this mirror adds nothing to the package.
